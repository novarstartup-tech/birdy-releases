Politique de confidentialité — BIRDY ERP

Dernière mise à jour : 13 août 2026

BIRDY ERP (« l'application ») est un logiciel de gestion d'entreprise qui s'exécute sur votre ordinateur. Cette politique explique quelles données l'application traite et comment.

1. Responsable

L'application est éditée par NOVAR. Pour toute question relative à cette politique : bahmamadoubobosewa@gmail.com.

2. Vos données restent sur votre ordinateur

Toutes les données que vous saisissez dans BIRDY ERP (clients, ventes, achats, stock, comptabilité, paie, etc.) sont enregistrées localement sur votre ordinateur, dans une base de données locale. Ces données ne sont pas transmises à l'éditeur ni à aucun serveur tiers — nous n'y avons pas accès. Les sauvegardes que vous créez sont stockées à l'emplacement que vous choisissez sur votre machine.

3. Aucun suivi

L'application ne collecte aucune donnée d'analyse ni de télémétrie. Aucune information d'usage n'est envoyée.

4. Connexion Google (optionnelle)

Si vous choisissez de vous connecter avec Google, l'authentification est gérée par Google. L'application reçoit uniquement les informations de base de votre compte (adresse e-mail, nom) nécessaires à la connexion. Ce traitement est soumis à la politique de confidentialité de Google.

5. Envoi d'e-mails (optionnel)

Si vous configurez l'envoi d'e-mails (par exemple pour transmettre une facture à un client), les messages sont envoyés via le service de messagerie que vous configurez (votre serveur SMTP ou le service intégré). Le contenu et les destinataires sont ceux que vous définissez.

6. Données partagées avec des tiers

BIRDY ERP n'échange de données qu'avec les services que vous activez : Google (connexion) et votre fournisseur d'e-mail (envoi). Aucun autre partage n'a lieu.

7. Sécurité

Vos données étant stockées localement, leur sécurité dépend de celle de votre ordinateur. Nous vous recommandons de protéger votre poste (mot de passe de session, sauvegardes régulières).

8. Vos droits

Vous gardez le contrôle total de vos données : vous pouvez les consulter, les modifier, les exporter ou les supprimer directement dans l'application, à tout moment.

9. Contact

Pour toute question : bahmamadoubobosewa@gmail.com.
